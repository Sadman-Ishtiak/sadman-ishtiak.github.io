## 4. Stemming Using the NLTK Toolkit
stemming is a process of removing affixes from words to get to the root form of the word. Lemmatization is a more refined process of stemming. It takes into account the context of the word and returns the dictionary form of the word, which is also known as the lemma.

```py
import nltk
from nltk.stem import PorterStemmer, LancasterStemmer, SnowballStemmer

nltk.download('punkt')
nltk.download('punkt_tab')

ws = ['running', 'flies', 'happily', 'studies', 'generously', 'connected']
porter, lancaster, snowball = PorterStemmer(), LancasterStemmer(), SnowballStemmer('english')
print(f"{'word':12}{'porter':10}{'lancaster':12}{'snowball'}")

    print(f"{w:12}{porter.stem(w):10}{lancaster.stem(w):12}{snowball.stem(w)}")
```

## 7. POS Tag Ambiguity Resolution Using Transition and Emission Probabilities
The same word can carry different POS tags, "can" can be a modal (MD), a noun (NN) or a verb (VB), and "fish" can be a noun or a verb. To resolve this ambiguity we build a small Hidden Markov Model with **transition probabilities** `P(tag_i | tag_i-1)` and **emission probabilities** `P(word | tag)`, then run the Viterbi algorithm over the sentence "I can fish" to find the most probable tag sequence.

```py
import nltk
from nltk.tokenize import word_tokenize

nltk.download('punkt')
nltk.download('punkt_tab')

# Tag ambiguity: "can" -> MD / NN / VB,  "fish" -> NN / VB
tags = ['PRP', 'MD', 'VB', 'NN']

# Transition probabilities P(tag_i | tag_i-1); '<s>' = sentence start
trans = {
    '<s>': {'PRP': 0.6, 'MD': 0.05, 'VB': 0.05, 'NN': 0.3},
    'PRP': {'PRP': 0.01, 'MD': 0.50, 'VB': 0.39, 'NN': 0.10},
    'MD':  {'PRP': 0.05, 'MD': 0.01, 'VB': 0.84, 'NN': 0.10},
    'VB':  {'PRP': 0.10, 'MD': 0.01, 'VB': 0.04, 'NN': 0.85},
    'NN':  {'PRP': 0.05, 'MD': 0.20, 'VB': 0.30, 'NN': 0.45},
}

# Emission probabilities P(word | tag)
emit = {
    'PRP': {'i': 0.9},
    'MD':  {'can': 0.8},
    'VB':  {'fish': 0.4, 'can': 0.1},
    'NN':  {'fish': 0.5, 'can': 0.3},
}

sent = [w.lower() for w in word_tokenize("I can fish")]
print("Sentence:", sent)

# Viterbi: best tag sequence = argmax of prod P(tag|prev) * P(word|tag)
V = [{t: trans['<s>'][t] * emit[t].get(sent[0], 0) for t in tags}]
back = [{}]
for i in range(1, len(sent)):
    V.append({})
    back.append({})
    for t in tags:
        p, prev = max((V[i-1][pt] * trans[pt][t] * emit[t].get(sent[i], 0), pt) for pt in tags)
        V[i][t], back[i][t] = p, prev

# Backtrack
last = max(V[-1], key=V[-1].get)
best = [last]
for i in range(len(sent) - 1, 0, -1):
    last = back[i][last]
    best.insert(0, last)

for i, w in enumerate(sent):
    print(f"{w:6}", {t: round(V[i][t], 5) for t in tags if V[i][t] > 0})
print("Best tag sequence:", list(zip(sent, best)))
print("Probability      :", max(V[-1].values()))
```

the model tags the sentence as `[('i', 'PRP'), ('can', 'MD'), ('fish', 'VB')]`, the modal-verb reading wins because `P(MD | PRP) * P(can | MD)` is the strongest path through the sentence.

## 8. Grapheme-to-Phoneme (G2P) Conversion
G2P conversion turns the spelling of a word (graphemes) into its pronunciation (phonemes). the code first looks the word up in the CMU Pronouncing Dictionary, and for words that are not in the dictionary, like proper nouns, it falls back to rule-based letter-to-sound rules, longest match first.

```py
import nltk
from nltk.corpus import cmudict

nltk.download('cmudict')

cmu = cmudict.dict()

# Rule-based fallback for words not in the dictionary (longest match first)
rules = [('tch', 'CH'), ('igh', 'AY'), ('sh', 'SH'), ('ch', 'CH'), ('th', 'TH'),
         ('ph', 'F'), ('ck', 'K'), ('ng', 'NG'), ('ee', 'IY'), ('oo', 'UW'),
         ('ai', 'EY'), ('oa', 'OW'), ('a', 'AE'), ('e', 'EH'), ('i', 'IH'),
         ('o', 'AA'), ('u', 'AH'), ('b', 'B'), ('c', 'K'), ('d', 'D'),
         ('f', 'F'), ('g', 'G'), ('h', 'HH'), ('j', 'JH'), ('k', 'K'),
         ('l', 'L'), ('m', 'M'), ('n', 'N'), ('p', 'P'), ('q', 'K'),
         ('r', 'R'), ('s', 'S'), ('t', 'T'), ('v', 'V'), ('w', 'W'),
         ('x', 'K S'), ('y', 'Y'), ('z', 'Z')]

def g2p(word):
    word = word.lower()
    if word in cmu:                         # a) dictionary lookup
        return cmu[word][0], 'cmudict'
    out, i = [], 0                          # b) rule-based fallback
    while i < len(word):
        for g, p in rules:
            if word.startswith(g, i):
                out += p.split()
                i += len(g)
                break
        else:
            i += 1
    return out, 'rules'

for w in ['university', 'night', 'phone', 'school', 'nazrul', 'jkkniu']:
    ph, src = g2p(w)
    print(f"{w:12}{' '.join(ph):30}({src})")

w = input("Enter a word: ")
print(w, "->", ' '.join(g2p(w)[0]))
```

`university`, `night`, `phone` and `school` come straight from the dictionary, while `nazrul` and `jkkniu` are built by the fallback rules, for example `nazrul -> N AE Z R AH L`.

## 9. Text-to-Speech (TTS) for Converting Text into Audio
NLTK itself has no audio support, so gTTS fills the text-to-speech part. converting the given text into an audio file,

```py
from gtts import gTTS

msg = ("Jatiya Kabi Kazi Nazrul Islam University (JKKNIU) is a premier public university "
       "in Trishal, Mymensingh, established in 2006.")

# Text-to-Speech
tts = gTTS(msg, lang='en')
tts.save('jkkniu.mp3')
print("Text converted to speech: jkkniu.mp3")
```

## 10. Automatic Speech Recognition (ASR) for Converting Audio into Text
converting the audio file from task 9 back into text. the recognizer reads WAV files, so the MP3 is converted first with pydub, which needs ffmpeg installed.

```py
from pydub import AudioSegment
import speech_recognition as sr

# Convert MP3 to WAV (recognizer needs WAV)
audio = AudioSegment.from_mp3('jkkniu.mp3')
audio.export('jkkniu.wav', format='wav')
print("MP3 converted to WAV: jkkniu.wav")

# Speech-to-Text
r = sr.Recognizer()
with sr.AudioFile('jkkniu.wav') as source:
    audio_data = r.record(source)

text = r.recognize_google(audio_data)
print("Recognized:", text)
```
