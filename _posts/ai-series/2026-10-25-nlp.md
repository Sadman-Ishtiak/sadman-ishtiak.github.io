## Natural Language Processing (NLP)




<div style="border-left: 4px solid #1a5c9e; background-color: #f0f4f8; padding: 15px; margin: 20px 0; border-radius: 4px;">
<strong>📖 Natural Language Processing</strong>

**Natural Language Processing (NLP)** is a subfield of AI concerned with enabling computers to understand, interpret, and generate human language. It bridges the gap between human communication and computer understanding.

### Key Tasks in NLP
\begin{itemize}
    \item **Tokenization**: Splitting text into words or subword units.
    \item **Parsing**: Analyzing grammatical structure (syntax trees).
    \item **Named Entity Recognition (NER)**: Identifying entities like persons, organizations, locations.
    \item **Sentiment Analysis**: Determining the emotional tone of text.
    \item **Machine Translation**: Translating between languages (e.g., Google Translate).
    \item **Question Answering**: Answering questions posed in natural language.
    \item **Text Summarization**: Generating concise summaries of longer texts.
    \item **Speech Recognition**: Converting spoken language to text.
    \item **Relation Extraction**: Identifying relationships between entities in text.
\end{itemize}

### Applications of NLP
\begin{itemize}
    \item Chatbots and virtual assistants (Siri, Alexa, ChatGPT)
    \item Search engines and information retrieval
    \item Machine translation systems (Google Translate, DeepL)
    \item Spam detection and text classification
    \item Medical record analysis and clinical decision support
    \item Legal document review and contract analysis
\end{itemize}



<div style="border-left: 4px solid #2e7d32; background-color: #e8f5e9; padding: 15px; margin: 20px 0; border-radius: 4px;">
<strong>💡 NLP in Action</strong>

Consider the sentence: *``Apple Inc.\ purchased a startup in Cupertino.''*

NLP tasks applied:
\begin{itemize}
    \item **Tokenization**: {[Apple, Inc., purchased, a, startup, in, Cupertino, .]}
    \item **NER**: Apple Inc.\ (ORG), Cupertino (LOC)
    \item **POS Tagging**: Apple (NNP), purchased (VBD), a (DT), startup (NN), in (IN), Cupertino (NNP)
    \item **Relation Extraction**: \text{Acquired}(\text{Apple Inc.}, \text{startup})
    \item **Sentiment**: Neutral (factual statement)
\end{itemize}

</div>



### FOL and NLP Connection

First-order logic provides a formal representation for the meaning of natural language sentences. FOL can represent:
\begin{itemize}
    \item Quantified statements (``All students study AI'' $\rightarrow$ $\forall x \; \text{Student}(x) \Rightarrow \text{Studies}(x, \text{AI})$)
    \item Relationships (``John knows Mary'' $\rightarrow$ $\text{Knows}(\text{John}, \text{Mary})$)
    \item Complex logical structure (``If it rains, the ground gets wet'' $\rightarrow$ $\text{Rains} \Rightarrow \text{WetGround}$)
\end{itemize}

NLP systems often use logical forms as intermediate representations for semantic understanding. FOL-based inference enables question answering and reasoning over the extracted meaning.
